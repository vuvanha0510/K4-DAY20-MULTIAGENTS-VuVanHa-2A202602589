description: Use this skill when writing or refactoring Python code to ensure all type annotations, documentation, naming conventions, and changelog updates are complete.
---
- Add explicit type annotations to all parameters and return values for every public function and method (names not starting with an underscore).
- Follow exact string normalization and formatting rules specified in requirements (such as case conventions, replacement of separators, and canonical naming).
- Record every bug fix or feature update in the changelog under the designated heading and bullet format.
- Run type checkers and test runners to verify correctness prior to completion.
